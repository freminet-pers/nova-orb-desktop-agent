# Roadmap

## Next major iteration: visual redesign

当前形象是为了验证桌面交互和状态反馈而做的过渡版本，完成度还不够，确实比较丑。下一版的第一优先级是形象本身，而不是继续增加更多功能。

计划方向：

- 重新设计主体轮廓、比例、材质和面部识别点；
- 让待机、思考、工作、成功、失败和语音状态共享一套更统一的视觉语言；
- 减少当前高光、轨道和粒子之间的拼接感；
- 保留低占用、离线渲染和可测试的状态契约；
- 重新制作品牌图标、预览图和安装包截图；
- 之后再考虑英文 UI、本地化文档和正式安装器。

## 当前版本之后

- 在更多 Windows DPI、多显示器和真实音频设备上做人工验收；
- 继续完善模型缺失、麦克风断开、API 错误和进程退出时的可见反馈；
- 维持 Agent 的最小权限边界，不用“任意命令执行”换取演示效果；
- 在许可证和第三方模型分发边界明确后，再决定是否开放更宽松的再分发权限。
