# Roadmap

Nova Orb 目前的工作重点是让 v0.2.0 这条“低打扰视觉状态 + 受限桌面操作”的主线可验证、可维护、可被安全地试用。路线图不是已发布功能清单；标为“评估”或“待维护者决定”的项目不会出现在当前下载选项中。

## 下一阶段：验证与收口

- 在更多 Windows DPI、多显示器、桌面背景和显卡驱动上人工验收透明窗口、gaze 和设置页；
- 使用真实音频设备复核模型缺失、麦克风断开、唤醒失败、进程退出和声纹误判时的可见反馈；
- 保持 Agent 的最小权限边界：只扩展经过审查的命名工具，不以任意命令执行换取演示效果；
- 为便携包补齐模型来源、许可、SHA-256、未签名/SmartScreen 说明和可复现的发布检查；
- 将 README、安装文档、发布说明和变更记录保持在同一版本语义下。

## 之后再评估

- 更自然但仍然低频的微动作和状态过渡，前提是不会削弱状态可读性和低打扰目标；
- 英文 UI、其他本地化文档和完整国际化；
- 正式安装器（例如 MSI）及代码签名；
- 是否提供不同模型/资源体积的构建变体（例如 Lite/Full）；在真实构建、许可和下载验证前，不把它们称为现有版本；
- 项目代码和原创视觉资产的正式许可证选择；当前许可证状态仍需维护者单独决定。

## 不在当前承诺内

- 任意 shell、PowerShell、权限提升、隐藏进程或高风险电脑控制；
- 移动端、macOS、Linux 发行版支持；
- 英文完整 UI、已签名安装包、自动化演示视频；
- 以“离线”一词掩盖 API、搜索或第三方模型的联网/许可边界。

完成项目需要同时更新实现、测试、文档和发布清单；只有在公开证据和目标 Windows 验收都具备时，路线图条目才应移入变更记录或发布说明。
