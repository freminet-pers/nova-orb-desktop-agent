# 文档目录

这里是 Nova Orb 公开仓库的文档入口。先看根目录 [README](../README.md) 了解定位和可验证工作流，再按需要进入下列页面。

| 文档 | 适合回答的问题 |
| --- | --- |
| [安装与配置](INSTALL.md) | Windows 便携 ZIP、源码运行、API/联网、用户数据位置和常见故障 |
| [架构说明](ARCHITECTURE.md) | Qt 宿主、Nova renderer、状态服务、语音和受限 Agent 工具如何分工 |
| [v0.2.0 发布说明](RELEASE_NOTES_v0.2.0.md) | 当前预览版的范围、验证记录、包体、校验值和已知边界 |
| [发布检查清单](RELEASE_CHECKLIST.md) | 维护者发布新版本前要核对的资产、许可、隐私和真实设备事项 |
| [路线图](ROADMAP.md) | 已确认的验证工作，以及仍需维护者决定的方向 |
| [v0.1.0 历史发布说明](RELEASE_NOTES_v0.1.0.md) | 保留早期公开版本的历史上下文 |
| [公开历史记录索引](archive/README.md) | 如何保留可复核的过程记录，同时拒绝私人素材和构建废料 |

## 公开素材边界

`docs/images/` 只放已经进入公开仓库、可用于 README/文档的真实截图。这里不存放原始照片、视频、录音、模型权重、数据库、日志、构建包或未脱敏的内部报告；这些内容也不应通过历史归档绕过仓库边界。
